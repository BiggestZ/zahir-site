To publish a new post:

1. Create a file in `content/blogs` using `.md` or `.mdx`.
2. Add frontmatter with at least `title`, `date`, and `description`.
3. Write your content in markdown.

Example frontmatter:

```yaml
---
title: "My Post"
date: "2026-02-23"
description: "What this post is about"
---
```

That is all. The post list and route are generated automatically.
